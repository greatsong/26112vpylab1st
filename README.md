# 빛나는 컬러 피아노: 건반을 누르면 그 음의 색으로 빛나고, 버튼으로 악기를 바꾸거나 곡을 연주합니다.

VPyLab에서 만든 3D 파이썬 프로젝트입니다.

## 바로 가기

- [실행 화면(GitHub Pages)](https://greatsong.github.io/26112vpylab1st/)
- [저장소](https://github.com/greatsong/26112vpylab1st)

프로젝트를 만든 직후에는 실행 화면이 준비되는 데 1~2분이 걸립니다.

## 파일

- `main.py`: 최신 코드입니다. 저장할 때마다 바뀝니다.
- `log.md`: 첫 항해일지를 작성하면 생기는 팀 활동 기록입니다.
- `history.md`: 저장한 시각, 메시지, 작성자를 기록합니다.
- `index.html`: 실행 화면입니다. 저장할 때마다 새로 만듭니다.

## 저장 기록

[Commits](https://github.com/greatsong/26112vpylab1st/commits)에서 저장할 때마다 바뀐 내용을 확인할 수 있습니다.
